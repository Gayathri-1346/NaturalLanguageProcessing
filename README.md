# NATURAL LANGUAGE PROCESSING AND APPLICATIONS LAB

## List of Experiments

1. Write a Python program to tokenize a sentence into words and then apply stemming and lemmatization using NLTK.

2. Implement a basic rule-based sentence boundary detector using regular expressions.

3. Using a small corpus, implement a topic segmentation algorithm to detect boundaries between topics.

4. Write a program that takes a sentence as input and tags each word with its Part-of-Speech (POS) using the NLTK library.

5. Implement stop words removal for a given text and evaluate its performance in reducing noise in text data.

6. Implement a basic shift-reduce parser in Python and parse a simple sentence.

7. Develop a Python program that uses WordNet to identify the correct sense of a word in a sentence.

8. Implement a simple named entity recognition (NER) system using spaCy to identify entities such as persons, organizations, and locations in a text.

9. Use the AllenNLP library to perform semantic role labelling on a given sentence.

10. Write a Python program to clean text data (removal of punctuation, lowercasing, etc.) using NLTK or Keras and prepare it for model input.

11. Implement a simple neural network model using Keras to classify text data into different categories.

12. Develop a program to generate word embeddings using the Gensim library and visualize the embedding space for a set of words.

13. Write a Python program to implement a Bag-of-Words model on a movie review dataset and perform sentiment analysis.

14. Implement a recurrent neural network (RNN) for document classification using Keras and evaluate its performance on a labeled dataset.

15. Build a character-level language model using an LSTM in Keras and train it on a small text dataset.
